# GitHub Model Atlas — Content-Based v1.0

## Scope

This atlas is based on the extracted contents of the current `08_Github` folder.

Read files:

```text
39 Markdown files
```

This version is no longer only index-grounded. It uses the actual Markdown files in `08_Github`, including root orientation files, model/framework files, diagnostics documents, and governance-facing documents.

## Purpose

The GitHub layer currently works as a public-facing surface of Meta-Writing Ecology. The individual Markdown files are readable as standalone model nodes, but the repository can still appear as a flat list of filenames.

This atlas converts that flat list into a navigable model field.

## What this atlas does

```text
file list
→ semantic fields
→ entry sequence
→ relation map
→ reader-specific paths
```

## What this atlas does not do

```text
It does not replace the original README.
It does not rewrite the model files.
It does not create new theory entries.
It does not include unpublished corpus material outside the uploaded 08_Github folder.
It does not treat inferred relations as final ontology.
```
