Machine Reading Path and Inference-State Map

A step-by-step simulator of how public-source reading rules execute: what was accessed, what boundary material was loaded, what claims are supported or blocked, what limitation language is required, and which public source rule supports each decision.

  • Draft
  • Public-source-only reference implementation
  • Local prototype
  • Not a search interface

What this is and is not

  • This is a public-source-only reference implementation of reading boundaries.
  • It does not represent third-party AI internal reasoning, a chain of thought, a confidence or truth score, the internal Registry, a complete MWE policy, a formal ontology, or an automatic authority system.

Unresolved means insufficient public evidence, not system failure or falsehood. Authorial confirmation required is an authority boundary, not a confidence score or a machine deficiency.
