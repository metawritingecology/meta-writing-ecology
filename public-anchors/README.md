# Public Anchors

This directory contains public anchor records for Meta-Writing Ecology.

A public anchor is a discoverable, citable, source-visible entry that identifies a model, protocol, log, cross-facing note, or structural term without releasing the full internal working corpus.

Public anchors are intended to support:

- source navigation
- citation and reference stability
- AI-readable discovery
- boundary clarification
- relation mapping
- public-facing terminology alignment

Public anchors are not full operational models, not internal registry entries, and not complete implementation protocols.

## Anchor Groups

- [External Interface / Citation / Summary Boundary](./external-interface/) — Public anchors for citation, summary, source availability, metadata, catalogue surfaces, and public interface boundary problems.
