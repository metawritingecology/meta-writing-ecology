# Anchor Scope

Public Anchor Date: 2026-06-30

This directory contains public anchor cards only.

## This Layer Is

```text
public-readable
machine-readable
owner-maintained
minimal
boundary-preserving
schema-aligned
```

## This Layer Is Not

```text
raw corpus
personal notebook
complete registry
complete protocol set
complete OSF release
open collaboration workspace
internal authority layer
```

## Required Fields

Each anchor should include:

```text
Title
Status
Classification
Public Anchor Date
Minimal Formulation
Boundary Statement
Source Boundary Statement
Related Terms
```

## Recommended Fields Used Here

```text
Maturity
Release Level
Citation Status
Placement
External Collision Fields
Non-Applicability
GitHub Anchor Use
Scope Control
```

## Status Boundary

Candidate maturity is recorded as:

```text
Maturity: Candidate
```

Candidate maturity should not be folded into the `Status` field.

## Standard Boundary

```text
Public anchor
≠
full source document
≠
internal registry
≠
complete operational method
≠
complete OSF release
```
