## Minimal Formulation

Premature Circulation describes the condition in which an element enters movement before adequate recognition, verification, accountability, or structural positioning has matured.

The model begins from the distinction:

```text
circulation
≠
recognition
```

and:

```text
movement
≠
structural accountability
```

In compressed form:

```text
portable form
→ assumed recognizability
→ circulation threshold crossed
→ recognition lag
→ contact multiplication
→ verification displacement
→ reactive recognition
→ downstream correction
→ circulation residue
```

A related subcondition is **Pre-Recognized Circulation**:

```text
pre-recognized circulation
=
movement under assumed recognition
before adequate recognition has occurred
```

Premature Circulation describes the broader timing failure.

Pre-Recognized Circulation describes the status condition that often enables it.

Together, the model describes cases where an element becomes:

```text
transferable before interpretable
shareable before accountable
portable before situated
repeatable before understood
searchable before verified
displayable before contextualized
citable before structurally recognized
operational before responsibly placed
```

The system fails not because the element cannot be seen.

It fails because the element moves before the system knows what it is moving.

## Core Characteristics

The Premature Circulation Model treats circulation as a structural threshold rather than simple communication, spread, virality, or publication.

Its core characteristics include:

- **Circulation threshold** — the point at which an element enters pathways of handling, repetition, distribution, publication, recommendation, indexing, routing, citation, display, reuse, workflow transfer, or operational movement.
- **Pre-recognized object** — an element that circulates under the assumption that it is already recognizable, classifiable, ordinary, usable, or handleable.
- **Recognition lag** — the delay between movement and adequate structural recognition of source, function, status, boundary, consequence, or operational role.
- **Verification lag** — the condition in which source checking, provenance reconstruction, contextualization, or classification review occurs only after movement has begun.
- **Contact multiplication** — the expansion of interpretive contact across users, platforms, institutions, documents, systems, archives, and downstream actors before recognition stabilizes.
- **Shareable-before-accountable condition** — circulation occurs before responsibility for movement, correction, interpretation, or consequence is structurally assigned.
- **Reactive recognition** — recognition occurs after circulation has already produced effects, rather than before movement begins.
- **Downstream correction** — later actors inherit the work of verification, contextualization, containment, correction, or repair.
- **Circulation residue** — persistent traces left after movement, including screenshots, citations, summaries, cached pages, derivative outputs, reports, memories, institutional records, or platform traces.

The model does not claim that all circulation is harmful.

It asks when movement begins before the system has formed adequate recognition and accountability for what is moving.

## Structural Logic

Premature Circulation follows a recurring sequence:

```text
element appears portable
→ element appears familiar or already recognizable
→ circulation begins
→ recognition remains incomplete
→ contact multiplies
→ verification moves downstream
→ consequences accumulate
→ recognition becomes reactive
→ correction becomes more costly
→ circulation residue persists
```

The usual assumed order is:

```text
recognize
→ classify
→ verify
→ position
→ circulate
```

Premature Circulation reverses or disrupts that order:

```text
circulate
→ interpret under pressure
→ verify downstream
→ correct after consequence
```

Once circulation begins, recognition no longer occurs in a static field.

It occurs after movement has already produced contact, memory, uptake, citation, platform visibility, institutional dependency, or derivative use.

The object is no longer only what it was before circulation.

It is also what movement has made it.

## Primary Circulation Patterns

### 1. Pre-Recognized Transfer

```text
surface familiarity
→ assumed recognition
→ transfer begins
```

The element moves because it appears already understandable.

The system does not recognize that recognition remains incomplete.

---

### 2. Portable-Before-Situated Circulation

```text
object becomes portable
→ context remains unstable
→ movement begins
```

The object travels before its field position, source relation, or operational status has been established.

This is common with excerpts, screenshots, summaries, generated outputs, dashboard values, and labels.

---

### 3. Shareable-Before-Accountable Circulation

```text
content becomes shareable
→ responsibility remains unclear
→ downstream actors inherit burden
```

The system enables distribution before assigning accountability for interpretation, verification, correction, or consequence.

---

### 4. Search-Summary Circulation

```text
source material compressed
→ summary becomes visible
→ summary circulates as access point
→ source structure remains unexamined
```

The summary becomes the moving object, even when its compression pathway remains unclear.

---

### 5. Synthetic Evidence Circulation

```text
synthetic media borrows evidentiary form
→ recognition as image / audio / video occurs
→ production condition remains unresolved
→ circulation multiplies contact
```

The surface moves as if it were evidence before evidentiary status has been established.

---

### 6. Agentic Trace Circulation

```text
agentic system produces trace
→ trace appears procedurally complete
→ trace circulates as accountability surface
→ action path remains unresolved
```

The trace moves as if it explains the action while authorization, causality, tool sequence, or responsibility remain unclear.

---

### 7. Institutional Template Circulation

```text
document matches institutional form
→ template travels
→ process / evidence / responsibility unclear
```

The template moves because it looks administratively valid.

The structure behind the template may remain unrecognized.

---

### 8. Dashboard Output Circulation

```text
metric displayed
→ dashboard value circulates
→ proxy structure remains opaque
```

The number, score, category, or label moves as a stable object while measurement conditions, proxy selection, or representational compression remain underexamined.

---

### 9. Reactive Containment

```text
premature circulation detected
→ correction attempted
→ prior movement must be contained
```

The system responds after circulation.

Containment becomes more difficult than prevention because the element has already entered memory, workflow, citation, platform traces, or institutional use.

---

### 10. Circulation Residue

```text
correction issued
→ traces persist
→ downstream systems retain prior movement
```

Even when recognition improves, circulation residue may remain.

The field does not return to its pre-circulation state.

## Distinction

Premature Circulation is not ordinary circulation.

```text
ordinary circulation
= movement appropriate to the object’s recognized status

premature circulation
= movement before adequate recognition, verification, accountability, or structural positioning has formed
```

Premature Circulation is not identical with Pre-Recognized Circulation.

```text
Premature Circulation
= broader movement-before-accountability condition

Pre-Recognized Circulation
= subcondition in which movement is enabled by assumed recognizability
```

Premature Circulation is not False Legibility.

```text
False Legibility
= readable before structurally recognized

Premature Circulation
= circulated before accountable

Pre-Recognized Circulation
= moved as if already recognizable
```

A false-legible form may or may not circulate.

A prematurely circulating form may or may not be false-legible.

They intersect when readable surfaces move before structural recognition.

Premature Circulation is not misinformation.

```text
misinformation
= false or misleading information

premature circulation
= movement before adequate structural recognition or accountability
```

Premature Circulation can occur without falsehood, deception, malicious intent, factual error, or viral spread.

The question is not only:

```text
Is this true?
```

The question becomes:

```text
Did this move before the system had the structural capacity to recognize, verify, contain, and become accountable for its movement?
```

## Application Scope

Premature Circulation may apply wherever elements move through systems before recognition, verification, or accountability stabilizes.

Relevant contexts include:

- AI-generated answers
- search summaries
- synthetic images, video, or audio
- agentic traces
- dashboard outputs
- automated classifications
- platform labels
- interface previews
- institutional templates
- policy documents
- media claims
- citations
- benchmark results
- dataset labels
- generated summaries
- workflow documents
- machine-mediated information environments
- meaning-bearing systems

In AI-mediated systems, generated outputs may become immediately reusable before source structure, uncertainty, or transformation pathway is inspected.

In search environments, summaries may circulate as remembered objects while source structure remains underexamined.

In synthetic media, evidentiary-looking forms may move faster than provenance reconstruction.

In agentic systems, traces may circulate as proof of completion before action paths are reconstructible.

In institutional workflows, documents, labels, recommendations, forms, or approvals may be routed before evidence, boundary, or responsibility structure is stable.

In platform governance, labels, warnings, badges, rankings, classifications, and moderation outcomes may become visible and actionable before their underlying pathways are understood.

## Non-Applicability

The model should not be used for every case of movement, sharing, publication, distribution, search visibility, or communication.

It does not apply well when:

- the object is adequately recognized before movement
- verification is proportionate to the circulation context
- accountability is clear before transfer
- the object is openly fictional, symbolic, provisional, or intentionally speculative
- circulation does not increase consequence
- movement is intentionally bounded and reversible
- the system preserves context during transfer
- correction is easy and non-consequential
- the issue is simple factual error rather than movement-before-recognition
- the analysis requires legal liability determination rather than structural mapping
- the object moves slowly but with adequate recognition and accountability
- circulation is ordinary publication under a clearly understood status

The model should not be used to claim that circulation is inherently harmful.

Its domain is narrower:

```text
circulation that begins before adequate recognition, verification, accountability, or structural positioning has formed
```

## Naming Declaration

The **Premature Circulation Model** originates within the Meta-Writing Ecology as a structural model for describing how elements enter circulation before adequate recognition, classification, verification, accountability, or structural positioning has occurred.

The term **circulation** does not refer only to communication, media spread, exchange, diffusion, virality, logistics, or public dissemination. It refers to entry into pathways of handling, repetition, distribution, publication, recommendation, indexing, routing, citation, display, reuse, workflow transfer, or operational movement.

The term **premature** does not refer merely to chronological earliness. It refers to movement before structural accountability has formed.

The term **Pre-Recognized Circulation** refers to the subcondition in which an element circulates under the assumption that it is already recognizable, classifiable, ordinary, or handleable, even though adequate structural recognition has not occurred.

This model does not claim that circulation is inherently harmful, nor that all movement must wait for complete certainty. It describes a narrower structural condition in which movement outruns recognition and converts later understanding into reactive interpretation.

This model does not refer to any specific platform, company, model, institution, user, incident, publication, or media object. It describes an abstract mechanism in which circulation begins before structural recognition and accountability stabilize.

This model is not derived from media theory, circulation theory, commodity exchange theory, diffusion studies, communication theory, virality research, misinformation studies, logistics, public communication studies, or platform governance literature, although intersections may exist.

This document constitutes the first OSF external-facing version of the Premature Circulation Model, integrating the internal Pre-Recognized Circulation formation as a core subcondition for analyzing movement-before-recognition, verification lag, reactive correction, downstream consequence, and circulation residue in AI-mediated, institutional, platform, and meaning-bearing systems.
